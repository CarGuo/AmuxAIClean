### 1.2 问题与改进建议

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| A1 | **能力面单一**：只有"问一行"`PathInquiry`，无批量/无聚类/无策略级问答 | 一次扫描得到 N 条候选时，用户无法用 AI 拿到"这一类是什么、能不能全勾"的整体结论 | 新增 `BatchInquiry`：把同一 vendor / 同一 ecosystem 下的 Top-K 路径打包问一次，返回"群组定性 + 建议默认勾选档"。仍由本地 Clamp 兜底。 |
| A2 | **无缓存 / 无去重**：同一路径多次"问 AI"重复出网 | 浪费 token、慢 | 引入按 `(path, mtime, bytes)` 哈希的会话内缓存（内存）+ 可选磁盘缓存（用户开关，默认关）。 |
| A3 | **temperature 固定，UI 不可调**（默认 0.2） | OK 对稳定 JSON，但探索式问答时偏死 | UI 给"模式"两档：精准（0.0）/ 解释（0.4），仍写入 [AISettings.temperature](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AIKit/Sources/AIKit/AISettings.swift#L62-L65)。 |
| A4 | **不支持本地模型即装即用**：Ollama 需要用户手填 `http://localhost:11434/v1` | 体验门槛 | 提供"本地模型"预设按钮（一键填 Ollama / LM Studio / vLLM 三选项）；自动探测本机是否在跑。 |
| A5 | **PromptBuilder 单文件硬编码 system prompt** | 多语种、不同模型偏好难调 | 抽出 prompt 资源文件（中/英），按 `Locale.current` 选；保留 `clamp` 不变。 |
| A6 | **错误兜底有限**：HTTP 429 / 5xx 无重试、无退避 | 网络抖动时 UI 直接报错 | 在 [OpenAIChatClient.ask](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AIKit/Sources/AIKit/OpenAIChatClient.swift#L62-L128) 加 1 次指数退避重试（仅幂等 POST 且非 401/400）。 |
| A7 | **缺审计日志**：用户事后无法回看"我之前问过哪些路径、AI 怎么答的" | 审计性差 | 复用 [LogKit](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/LogKit) `.settings` 频道写一行结构化记录（path 已脱敏）。 |
| A8 | **缺"AI 解释为什么默认不勾"** | 当前 AI 仅作为"主动问"入口，被动场景没用 | 在 [RowView](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AppUI/Sources/AppUI/RowView.swift) 的 `verdict == .confirm` 行内增加"问 AI 解释"小图标（仍是按需触发，不主动出网）。 |
| A9 | **PathInquiry.childPreview 限 5 条** 对超大目录信息量太少 | AI 经常说"信息不足请确认" | 升级到 Top-K（按子项大小，复用 [LargeFileLeafTopNHeap](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AppUI/Sources/AppUI/LargeFileLeafTopNHeap.swift)），并附上"该目录里最大 3 个子项"。 |
| A10 | **PromptBuilder 不显式声明"绝不输出代码"**，OpenAI 偶发在 reason 里塞命令 | 安全：用户可能照抄 `rm -rf` | system prompt 增加："严禁输出任何可执行命令"。 |

### 2.2 性能侧（潜在风险/可观测性缺口）

| # | 风险 | 建议 |
|---|---|---|
| P1 | `AsyncStream(.unbounded)` 在超大根（如整盘 5M+ 项）时 backlog 可能撑大堆内存 | 观察 [DirIndexMemoryFootprintTests](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AppUI/Tests/AppUITests/DirIndexMemoryFootprintTests.swift) 之外再补一条"事件 backlog 上限"基线测试；或将 yield 频率与消费者吞吐做一次软背压（actor await 已天然形成，但缺测量）。 |

## 3. 用户自定义全盘扫描评审

### 3.1 现状盘点
- 类目模型 [ScanCategory](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AppUI/Sources/AppUI/ScanCategory.swift) 已区分 `preset / custom / fullDisk / largeFiles` 四类。
- 用户自定义路径 [UserPathStore](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/AppUI/Sources/AppUI/UserPathStore.swift) actor 化、UserDefaults 持久化，去重靠 `resolvingSymlinksInPath` + 末尾 `/` 修剪。
- 白名单 [WhitelistStore](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/SafetyKit/Sources/SafetyKit/WhitelistStore.swift)、glob 支持 [PathGlob](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/SafetyKit/Sources/SafetyKit/PathGlob.swift) 已就绪。
- 规则装载 [RuleLoader](file:///Users/guoshuyu/workspace/GSYCleanMac/Packages/SafetyKit/Sources/SafetyKit/RuleLoader.swift) 仅启动时加载 vendors.yaml，**不支持热加载**。

### 3.2 缺口
1. **没有用户规则编辑器 UI**：仅能加路径，不能新增匹配模式/标记 verdict。
2. **没有用户级 `custom_rules.yaml`**：一切修改要改仓库 YAML 然后重新 build。
3. **没有"扫描 Profile" 概念**：用户无法保存"我只跑 iOS 开发清理 + 大文件 Top200"这种组合。
4. **没有 glob 黑白名单 UI**：`~/Documents/**/.private_backup/**` 这种排除模式靠改代码。
5. **没有定时/计划任务**（菜单栏 Sentinel 部分能力存在但未公开）。
6. **不能"按需追加 vendor"**：例如临时加一个 `~/MyProject/dist`。

**完整规划见 [CUSTOM_SCAN_PLAN.md](file:///Users/guoshuyu/workspace/GSYCleanMac/docs/CUSTOM_SCAN_PLAN.md)。**
