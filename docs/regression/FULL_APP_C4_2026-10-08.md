## 数据和操作范围

| 数据集 | 用途与边界 |
|---|---|
| R 只读真实数据 | 工程 `Resources`、用户已有扫描根、安装软件与系统指标。只读扫描、搜索、选择、确认取消；可添加/移除待处理引用并核对原文件哈希，不回收日常文件，不结束业务进程。 |
| F 自建文件 | UUID 独立目录，预建多层目录、普通文件、隐藏项、中英文及空格名称、同内容副本、近似副本、跨目录硬链接、软链和断链、FIFO。manifest 记录路径、类型、inode、大小、mtime 和普通文件哈希。所有真回收只涉及 manifest 内条目。 |
| V 大数据 | F 内独立子集：大量小文件、深目录、超过大文件阈值的实写文件。独立 metadata 得出 allocated 与 logical 参考值；不把稀疏文件逻辑大小当磁盘占用。 |
| P 自建进程 | 测试启动的环回监听进程；记录 PID、启动身份、端口。App 只终止这些进程。Dart 正向场景需要真实 Dart 可执行文件，不能改进程名冒充。 |
| E 隔离环境 | 单独 macOS 测试账户或 VM 内的测试 App、Homebrew 缓存、模拟器与登录项。系统维护、managed uninstall、清日志、启动恢复故障与实际权限切换在此执行。 |
| A 可选 AI | 经用户允许的已配置端点，仅发送人工 fixture 元数据；不读取或输出 Key，不发送真实文件内容，不为测试新增网络能力。 |

## 运行次序与通过标准

1. 环境与事务预检，冻结待测构建身份。先解决真回收数据边界，再进行 P0 回收和 Undo。
2. 普通模式与专业 List、Tree、大文件共享扫描模型，逐入口回归同步和独立的动作路由。
3. 工具、四个开发工作流、待处理、设置、菜单、窗口和生命周期。
4. 中文/英文、取消、权限、旧任务、连续操作与大目录响应性。
5. 发现问题时保留失败现场，定位共同根因，补有意义的聚焦测试，修复后跑要求的包测试与
   Debug 构建，再在新构建持续会话中复测失败步骤及所有共享入口。

每项使用 `待测 / 部分完成 / 通过 / 失败 / 受阻 / 不适用`。部分完成不能计作整项通过。
受阻必须注明具体资源或授权；不适用只用于
当前产品确实没有的能力，不能把环境没有数据当作正向场景通过。现有工具例如 Homebrew
已安装/过期页是只读展示，不计划产品尚未提供的升级或卸载按钮。

一次通过必须同时具备：实际点击/键盘操作、可观察终态、必要的文件系统或进程侧核对、
对应截图/AX/日志。回收需要真实移动成功及行/选择/详情/统计同步；Undo 需要实际文件恢复、
无需再次点击即可显示。异常需要正确原因与恢复动作；不得永远 loading 或错误提示授权。
非模态成功提示不抢焦点、不要求 Done；部分失败与不确定提交仍保留可审阅明细。
